# 🚉 BlupTrain - Sistem Tiket Kereta Sederhana  

**BlupTrain** adalah aplikasi sederhana berbasis Java yang dirancang untuk mengelola operasi tiket kereta. Proyek ini berfokus pada implementasi fungsi dasar CRUD (Create, Read, Update, Delete) untuk menangani data tiket dengan efisien. Cocok untuk pembelajaran atau sebagai portofolio pemrograman Java.  

## ✨ Fitur:  
- ➕ **Create**: Menambahkan data tiket baru dengan detail penumpang.  
- 🔍 **Read**: Melihat informasi tiket yang telah terdaftar.  
- ✏️ **Update**: Memperbarui detail tiket jika diperlukan.  
- ❌ **Delete**: Menghapus data tiket yang sudah tidak diperlukan.  

## 🛠️ Teknologi yang Digunakan:  
- 💻 **Bahasa Pemrograman**: Java  
- 🗄️ **Basis Data**: SQLite/MySQL (atau DBMS lain sesuai kebutuhan)  kalo ingin di kembangkan
- 📚 **Framework/Library**: Tanpa framework, hanya menggunakan Java murni  

## 🎯 Tujuan:  
Proyek ini dibuat untuk tujuan edukasi, khususnya bagi mahasiswa atau pengembang pemula yang ingin memahami konsep dasar pemrograman Java dan implementasi operasi CRUD dalam konteks sistem tiket kereta.  

## 🚀 Cara Penggunaan:  

1. **Clone Repository**  
   ```bash  
   git clone https://github.com/username/bluptrain.git  
   cd bluptrain  
   ```  

2. **Setup Database**  
   - Pastikan database sudah diatur (gunakan SQLite/MySQL).  
   - Import file SQL yang disediakan (`schema.sql`) kalo ingin di kembangkan

3. **Kompilasi dan Jalankan Program**  
   ```bash  
   javac BlupTrain.java  
   java BlupTrain  
   ```
